# 🎵 Audio & Custom Sounds

Um das Projekt frei von urheberrechtlich geschützten Audio-Dateien zu halten, liefert das Repository keine proprietären Musikdateien mit.

### Eigene Heimweg-Lieder hinzufügen:
Lege deine Lieblingslieder einfach auf deinem Computer in folgendem Benutzerverzeichnis ab:
```
~/.config/deskimoni/sounds/gohome/
```

Unterstützte Formate: `.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a`.

Wenn Deskimoni von einem anderen Bildschirm nach Hause watschelt (oder du im Menü / Chat „pfeifen“ sagst), wählt er automatisch zufällig einen Song aus diesem Ordner ab. Ist der Ordner leer, pfeift er eine synthetische Melodie.
